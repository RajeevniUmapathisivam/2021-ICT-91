# Dataset Description

This folder contains the dengue virus nucleotide sequences used in the comparative genomic analysis.

The dataset contains eight sequences retrieved from the NCBI GenBank database.

Four dengue virus serotypes are included:

- DENV-1: KM204119, EU848545
- DENV-2: KM204118, AF038403
- DENV-3: KU050695, M93130
- DENV-4: KR011349, AY947539

The sequences were downloaded in FASTA format using the rentrez package in R.
