# Analysis Results

This folder contains the outputs generated during the comparative genomic analysis of dengue virus sequences.

## Output Files

| File | Description |
|---|---|
| nucleotide_analysis.csv | Nucleotide frequencies and GC content |
| genome_length_comparison.png | Genome length comparison graph |
| gc_content_comparison.png | GC content comparison graph |
| aligned_dengue_sequences.fasta | Multiple sequence alignment |
| genetic_distance_matrix.csv | Pairwise genetic distance matrix |
| genetic_distance_heatmap.png | Genetic distance visualization |
| phylogenetic_tree.png | Neighbor-Joining phylogenetic tree |
| phylogenetic_tree.nwk | Phylogenetic tree in Newick format |

## Summary

The analysis compares eight dengue virus sequences representing DENV-1, DENV-2, DENV-3 and DENV-4.

The results include nucleotide composition, sequence similarity, genetic distances and phylogenetic relationships.
